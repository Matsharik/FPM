## Факты API (проверено 12.11 на 8790)
- `units=relative`: пороги и прогноз пересчитаны сервером («% к цели», 100/175/250) — линии порогов рисуем в обоих режимах.
- `GET /api/deviations?node=11` возвращает DEV-0001 (фильтр учитывает первопричину).
- Ручная карточка есть: `POST /api/deviations {node_id, kpi, hypothesis}` → 201 даже на зелёном KPI («превентивная карточка»).
- Флажок решения: `POST /api/qc/kpi/{node}/{kpi}/flags {ts, kind:"decision", label, ref}` → 201, на статус не влияет; вне зоны 403, у builder нет `flags.write`.
- Перепроверка → `{recheck, deviation}`; pending: `elapsed_days`, `min_days`.
- `priority` плиток: time×4, quality×2, cost×1 («Команда»), other×1 («Клиенты»). Индикаторы «Срок · Качество · Себестоимость» — по time/quality/cost.
- Риск после сброса: «Клиенты · Лиды за сутки — внимание через 8 дн. (1 дек)» (с 1 декабря сезонный профиль).
- После +7 дней у плиток меняется главный KPI → «Что изменилось» сравнивает значение только у того же KPI.
- После +7 дней до перепроверки карточка `overdue: true`.
- `crossings.*.already: true` важнее `in_days`.
- `head_prod` видит карточку без цифр сигнала; `builder` видит Пульс и карточку только на чтение.
- Журнал пишет каждое `GET /api/nodes/{id}` и `/api/deviations/{id}` → их не рефетчим по фокусу.

## Стек
Vite 8 · React 19 · TypeScript 5.x strict · react-router 7 (HashRouter) · TanStack Query 5 · @xyflow/react 12 + elkjs · recharts 3 (KpiChart), свой SVG Sparkline · @floating-ui/react · lucide-react · @fontsource-variable/inter · openapi-typescript · vitest · @playwright/test (скриншоты).
Стили — `tokens.css` + CSS Modules. Состояние — URL + кэш Query; `as`/`units` переносит общий хелпер ссылок; `panel=` читает один InspectorHost.
