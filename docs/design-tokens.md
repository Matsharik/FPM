# Дизайн-токены «Фотопринт Manage» (FPM) — для слайдов

Источник правды — `frontend/src/styles/tokens.css` и страница интерфейса `#/ui`.

## Принципы
1. **Цвет = смысл.** Почти монохромный интерфейс; цветом говорят только статусы.
2. **Один жёлтый элемент на экране — следующий шаг.** Жёлтый `#FFE600` — только заливка с чёрным текстом или подсветка выбранного вместе с чёрной обводкой. Никогда не текст и не линии на светлом фоне.
3. **Статус = цвет + значок + слово.** «Внимание» — оранжевый (жёлтый занят брендом).
4. **Крупные цифры, мало слов.** Табличные цифры, плотный трекинг у крупных значений.
5. **Денег нет** — только статусы, доли, индексы.

## Цвета
| Токен | HEX | Назначение |
|---|---|---|
| bg | `#F4F4F5` | фон приложения |
| surface | `#FFFFFF` | карточки, панели |
| ink | `#0A0A0A` | кнопки, обводка выбора, фокус |
| text | `#1C1C1E` | основной текст |
| text-muted | `#5F5F66` | вторичный текст (контраст 5,9:1 на фоне) |
| border | `#E4E4E7` | разделители |
| accent / on-accent | `#FFE600` / `#0A0A0A` | главное действие, выбранный элемент |
| ok / ok-ink / ok-soft | `#1E9E55` / `#0B6B39` / `#E7F6EE` | Норма ✓ |
| warn / warn-ink / warn-soft | `#FF8A00` / `#A85400` / `#FFF1E0` | Внимание ! |
| crit / crit-ink / crit-soft | `#E5383B` / `#B4232A` / `#FDECEC` | Критично ✕ |
| unknown / unknown-ink / unknown-soft | `#A1A1AA` / `#52525B` / `#F1F1F3` | Нет данных – |
| impact | `#3B5BDB` | «Показать влияние» (не статус) |
| hatch | штриховка 135° `#E4E4E7` по `#F4F4F5` | узлы вне зоны |

`*-ink` — для текста, остальные — для заливок, полос и значков.

## Шрифт
Inter (вариативный, локально, с кириллицей). Запасные: SF Pro Display, Segoe UI, system-ui.
Шкала: 12 / 14 / 16 / 20 / 28 / 40 / 56 px. Крупные значения — вес 600, трекинг −2 %. Основной текст не меньше 14 px.

## Статусы
- KPI и плитки: Норма (зелёный ✓) · Внимание (оранжевый !) · Критично (красный ✕) · Нет данных (серый –).
- Решения: Открыто · Назначено · В работе · Выполнено, ждёт проверки · Проверено: сработало ✓✓ (зелёный) · Проверено: не сработало (красный) · Эскалировано ↑ · Закрыто (серый) · Просрочено.
- Этапы заказа: Не начат · В работе · Готово · С опозданием (оранжевый) · Брак (красный).

## Геометрия
Сетка 8 px. Скругления: карточки 16 px, чипы 10 px, кнопки и пилюли — полностью скруглённые. Тени минимальные.

## Логотип
Жёлтый скруглённый квадрат (радиус 8 из 32) с чёрной буквой «F» и точкой-сигналом. Полное название «Фотопринт Manage» — в шапке и на входе, сокращение FPM — во вкладке браузера и мелких местах.
